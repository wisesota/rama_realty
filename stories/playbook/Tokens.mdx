# Rama Realty Design Token Architecture

The Rama Realty design system uses a code-first token pipeline compliant with the **DTCG (Design Tokens Community Group)** specification.

Design tokens are structured into three distinct layers:
1. **Primitives** (`tokens/primitives.json`): Raw values for color hexes, typography scales, spacing units, and border radii.
2. **Semantics** (`tokens/semantics.json`): Contextual intent abstractions (canvas surfaces, text hierarchy, interactive focus states, feedback).
3. **Components** (`tokens/components.json`): Component-scoped measurements and tokens (buttons, media frames, voice indicators).

## 🔤 Typography

- **Heading Font:** `Source Serif 4` (`tokens.primitives.font.family.serif`)
- **Body & Sans Font:** `Instrument Sans` (`tokens.primitives.font.family.sans`)

| Token Property | Generated TypeScript Path | Value | Usage |
| :--- | :--- | :--- | :--- |
| `font.size.xs` | `tokens.primitives.font.size.xs` | `0.72rem` | Eyebrow badges, tags, caption metrics |
| `font.size.sm` | `tokens.primitives.font.size.sm` | `0.84rem` | Interactive buttons, navigation links |
| `font.size.base` | `tokens.primitives.font.size.base` | `1.0rem` | Primary body prose |
| `font.size.lg` | `tokens.primitives.font.size.lg` | `1.12rem` | Subheadings, intro copy |
| `font.size.xl` | `tokens.primitives.font.size.xl` | `1.25rem` | Card titles, block headers |
| `font.size.2xl` | `tokens.primitives.font.size['2xl']` | `1.75rem` | Section headers |
| `font.size.3xl` | `tokens.primitives.font.size['3xl']` | `2.45rem` | Major title headers |
| `font.size.hero` | `tokens.primitives.font.size.hero` | `3.85rem` | Hero title (strictly 1 line at ≥1280px desktop) |

## 📐 Layout & Radii Rules

- **Corner Radii:**
  - `radius.media` (`tokens.primitives.radius.media`) = `16px` (Strict 16px architectural media frame corners).
  - `radius.content` (`tokens.primitives.radius.content`) = `0.625rem` (10px for cards, dialog panels, and workspace sheets).
  - `radius.control` (`tokens.primitives.radius.control`) = `0.5rem` (8px for compact interactive controls).
