# Rama Realty Design Token Architecture

The Rama Realty design system uses a code-first token pipeline compliant with the **DTCG (Design Tokens Community Group)** specification.

Design tokens are structured into three distinct layers:
1. **Primitives** (`tokens/primitives.json`): Raw values for color hexes, typography scales, spacing units, and border radii.
2. **Semantics** (`tokens/semantics.json`): Contextual intent abstractions (canvas surfaces, text hierarchy, interactive focus states, feedback).
3. **Components** (`tokens/components.json`): Component-scoped measurements and tokens (buttons, media frames, voice indicators).

## 🔤 Typography

- **Heading Font:** `Source Serif 4` (Editorial authority, balanced optical weighting)
- **Body & Sans Font:** `Instrument Sans` (Clear geometric precision for UI controls, body copy, and metadata)

| Token | CSS Variable | Value | Usage |
| :--- | :--- | :--- | :--- |
| `font.size.xs` | `--font-size-xs` | `0.72rem` | Eyebrow badges, tags, caption metrics |
| `font.size.sm` | `--font-size-sm` | `0.84rem` | Interactive buttons, navigation links |
| `font.size.base` | `--font-size-base` | `1.0rem` | Primary body prose |
| `font.size.lg` | `--font-size-lg` | `1.12rem` | Subheadings, intro copy |
| `font.size.xl` | `--font-size-xl` | `1.25rem` | Card titles, block headers |
| `font.size.hero` | `--font-size-hero` | `3.85rem` | Hero title (strictly 1 line at ≥1280px desktop) |

---

## 📐 Layout & Radii Rules

- **Corner Radii:**
  - `radius.media` = `0px` (Strict architectural discipline for luxury photography).
  - `radius.content` = `0.625rem` (10px for cards, dialog panels, and workspace sheets).
  - `radius.control` = `0.5rem` (8px for interactive button and input elements).
